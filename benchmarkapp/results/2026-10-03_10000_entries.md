# 10,000 entries — macOS arm64 vs web

Release builds, Apple Silicon Mac. Strings are ~100 characters (≈1 MB per
container). Every call is awaited one by one; the loop gives the event loop a
turn every 50 operations. Operations over 20 s are stopped ("timeout").

Times wait until the data is saved, as far as each API allows: Orca fsyncs
its main and backup file; Hive, Sembast and GetStorage write without fsync;
SharedPreferences on Apple platforms hands values to `NSUserDefaults`, which
writes later; on the web everything is in localStorage / IndexedDB.

UI stall during the bulk write / delete of 10,000 entries (strings):
Orca ~100 ms (both variants), Hive 3.5 ms, SharedPreferences 23 ms, Sembast
5 ms.

Orca's cold read with a password includes deriving the key (PBKDF2, 600,000
iterations, ≈41 ms on this Mac), once per container per app start.
